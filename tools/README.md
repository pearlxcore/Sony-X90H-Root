# Tools

Selected first-party tools from the research. Each directory has its own README.
The catalog, risk labels and what is not included are in
[../docs/TOOLS.md](../docs/TOOLS.md).

```
display/
  x90shot/          native panel still capture + A/B compare
  hdmi-view/        HDMI input viewer
  split/            split-screen A/B
  refresh-120hz/    Android UI 120 Hz helper
picture-control/    X90H Picture Control v0.2.0
recovery/           read-only boot/wipe analysis
capture/            X90CAP2 capture + cadence + x90-pq source
analysis/           logcat config parser (other firmware-specific helpers private)
modules/            experimental module sources
verify-exploit.sh   source/prebuilt hash + reproducible build check
```

These tools require the exact firmware and, for device tools, root. They are
not products and have no warranty.
